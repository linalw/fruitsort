# 压掉落：掉的是"开爪太早"，不是"没夹住"

> 一句话：掉落不是手指滑脱造成的，**是模型在离料框 15–27 cm 时就开爪**，果子直接掉在带子边上。
> 加一个**放料门**（只在框心 10 cm 内允许开爪，超时就放弃守卫）后，所有开爪都落在
> 4.9–9.7 cm，掉落明显下降。

诊断工具：`stream_eval.py --trace-drop --trace-release`。

## 1. 判定口径

环境里 `dropped` 的定义（`fruit_stream.py`）：

```python
dropped = (p[2] < 0.10 and not in_bin_xy) or abs(p[1]) > 1.2
```

即**掉到地上**或**甩出侧面**（`missed` 是留在带上被漏过，`delivered` 是进框）。
所以"掉落"不是"没抓住"——没抓住算 `missed`；掉落是**抓住之后又把它弄丢了**。

## 2. 证据：开爪点离框多远

`--trace-release` 打印每次"闭→开"瞬间 TCP 到本类框心的距离（只统计真的夹着东西的）：

```
[open] t= 10.3 apple ph=2 grasp=1 tcp=(-0.34,-0.10,0.56) d_bin=21.4cm  ← 还在带子上方
[open] t= 45.3 apple ph=2 grasp=1 tcp=(-0.51,-0.48,0.50) d_bin=20.2cm  ← 已经越过料框
[drop] t= 45.7 apple id=5  last=(-0.49,-0.43,0.13) bin=(-0.46,-0.28)   ← 落在地上
[open] t= 25.2 apple ph=2 grasp=1 tcp=(-0.46,-0.35,0.52) d_bin= 6.7cm  ← 这个才进框
```

料框 0.24 × 0.24（半宽 12 cm），所以 `d_bin ≥ 13 cm` 就是**开在框外**。统计一轮：

| 开爪点 | 次数 | 结果 |
| --- | --- | --- |
| `d_bin` 5–10 cm（框内） | 4 | 送达 |
| `d_bin` 13–27 cm（框外） | 6 | 掉落 |
| 越过料框（`dy` 同号且 > 12 cm） | 3 | 掉落 |

模型的相位是对的（`ph=2`，`grasp=1`），`--carry-latch` 也在，但它**连续 3 步以上**给出
"开爪"，所以锁存也拦不住——它是真的认为"可以放了"。

## 3. 修法：放料门

```bash
--release-gate 0.10 --release-wait 120
```

- 夹着东西 + 想开爪 + **距框心 > 10 cm** → 保持闭合，并把目标点直接设成框心
  （`tgt = (框x, 框y, max(tcp_z, 0.52))`）；
- 超过 `release-wait` 步（默认 6 s）就放弃守卫放开，避免"抱着果子跑整局"；
- 料框位置是**环境夹具**（安装时就已知），不是物体真值，所以这一条不违反"模型输入不含真值"。

效果（同 seed 60004，`--trace-release` 复核）：

| | 开爪点分布 |
| --- | --- |
| 无门 | 6.7 / 13.4 / 19.5 / 20.2 / 21.4 cm（一半在框外） |
| **加门** | 4.9 / 5.4 / 7.5 / 9.2 / 9.5 / 9.5 / 9.6 / 9.7 / 9.7 cm（全部在框内） |

## 4. 剩下的第二类掉落：搬运滑移

开了门之后仍有 1 次掉落，trace 显示：开爪时 TCP 在 `x=−0.39`，而果子最后位置在 `x=−0.28`
——果子比夹爪**滞后 11 cm**，说明它在搬运途中就在缓慢滑出指面（不是在开爪瞬间掉的）。

这条属于夹持本身（闭爪落在果心上沿、接触面积只有上半球），候选手段：

| 手段 | 状态 |
| --- | --- |
| 闭爪再压低 4 mm | 已试，**更差**（5/9，掉落 3），回退 |
| 搬运限速 `--carry-step-map apple=0.02` | A/B 中 |
| 夹持力/宽度设定点（`--width-g`） | 未试（需要标定"宽度→力"映射） |

## 5. 成对闭环（apple-only，slots 2，dense，60 s × 3 局/seed）

| 配置 | 60001 | 60002 | 60004 | 合计 | **掉落** |
| --- | --- | --- | --- | --- | --- |
| 闭爪高度门（v1.88） | 3/4 | 4/5 | 4/6 | 11/15 = 73% | **4** |
| **+ 放料门 0.10 m** | 3/4 | 4/5 | 3/5 | 10/14 = 71% | **1** |
| + 放料门 + 搬运限速 0.02 | 3/4 | 4/5 | 3/5 | 10/14 = 71% | 1 |

- **送达没掉（73% → 71%）**，掉落 **4 → 1**；逐种子同向（drop 1→0、1→0、2→1）。
- **搬运限速（0.02 m/步）完全没差别**（每个种子的数字都一模一样）→ 不是采纳项：
  说明剩下那 1 次掉落不是"搬太快甩出去"，而是夹持本身。
- 剩余掉落率：**4/15 → 1/14**（占送达件数的 27% → 7%）。

## 6. 复现

```bash
FRUITSORT_HEAD_FOV=1.62 FRUITSORT_HEAD_RES=1280x960 \
FRUITSORT_CALIB=overhead_homography_gemini.npy \
python scripts/stream_eval.py --ckpt runs/act-dagger/ckpt.pt --perception rgbd \
  --perception-targets --grasp-verify --decline-yaw 0.64 --decline-kinds strawberry,banana,pear \
  --close-z-gate-map apple=0.012 --close-z-off-map apple=0.0 \
  --release-gate 0.10 --belt 0.08 --seconds 60 --episodes 3 --slots 2 \
  --gap-min 1.5 --gap-max 2.5 --seed 60004 --trace-drop --trace-release
```
