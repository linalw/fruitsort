# 触觉模型架构（`act-ta-onslip`，v1.14）

> 与不带触觉的版本（`act-wide-4c`，obs 52）相比，唯一的结构差异是
> **状态输入多 9 维触觉**（49→58，加相位 61）+ **一个滑移辅助头**。骨干网络完全相同。

## 1. 数据流

```
                    ┌──────────────── 每步（30 Hz）────────────────┐
                    │ overhead RGB 96×96 ─┐                       │
                    │ wrist    RGB 96×96 ─┤ 各取最近 8 帧            │
                    │ 状态向量 61 维 ─────┤                       │
                    └─────────┬───────────┘                       │
                              ▼
        ┌───────────────────────────────────────────┐
        │ 图像 token（2 视角共享一个 ConvEncoder）   │
        │  input 4ch = RGB + |当前帧−上一帧|（运动线索）│
        │  ConvEncoder → 256 维向量                  │
        │  + view_type(视角嵌入) + time_pos(帧序号)  │
        ├───────────────────────────────────────────┤
        │ 状态 token                                │
        │  state_enc: 61 → 256 (Linear-GELU-Linear)  │  ← 触觉在这里进来
        │  + view_type(state) + time_pos             │
        ├───────────────────────────────────────────┤
        │ CLS token = 可学习 + kind_emb(指令水果)    │
        └───────────────┬───────────────────────────┘
                        ▼
     序列 = [CLS, (t0: oh, wr, st), (t1: oh, wr, st), … (t7: oh, wr, st)]
            共 1 + 8×3 = 25 个 token
                        ▼
        ┌───────────────────────────────────────────┐
        │ 编码器 4 层 Transformer (d=256, 8 头, ffn 768)│
        │ 因果 mask：帧 t 只能看 ≤t 的历史，CLS 可看全部│
        └───────────────┬───────────────────────────┘
                        ▼  memory (25×256)
        ┌───────────────────────────────────────────┐
        │ 解码器 4 层 Transformer，16 个可学习 query  │
        │ 每个 query cross-attend 到 memory          │
        │ + state_short(当前帧 61→256) 捷径            │
        └───────────────┬───────────────────────────┘
                        ▼
      ┌─────────────────┼──────────────────┬─────────────────┐
      ▼                 ▼                  ▼                 ▼
 act_head(256→4)×16  phase_head(256→3)×16  slip_head(256→1)  z_proj(CVAE 32→256)
 → 16 步 Δxyz+夹爪logit  → 每步 接近/下探/搬运   → 未来 0.5s 会否开始滑   → 加到每个 query
```

## 2. 状态向量 61 维（模型输入的"本体+触觉+相位"）

| 区间 | 维度 | 内容 |
| --- | --- | --- |
| `[0:7]` | 7 | TCP 位姿 `p(3)+q(4)`（`tcp_pose.raw_pose`） |
| `[7:16]` | 9 | 机器人 qpos（7 臂关节 + 2 指） |
| `[16]` | 1 | 传送带速度 |
| `[17:49]` | 32 | 4 类水果 × `[pos(3), vel(3), active, held]` |
| **`[49:58]`** | **9** | **触觉（见下表）** |
| **`[58:61]`** | **3** | **相位 one-hot（接近 / 下探 / 搬运）** |

训练与推理都用**原始值**（无额外缩放）；训练时按列 z-score（`Normalizer`）。

## 3. 触觉 9 维（`bc.build_tactile`，全部从仿真真值算）

| # | 名称 | 公式 | 抓住梨时实测 |
| --- | --- | --- | --- |
| 0 | `Fn` | `(|F_L·â| + |F_R·â|)/2`，`â`=两指连线单位向量 | 37.7 N |
| 1 | `Fasym` | `‖F_L·â‖−‖F_R·â‖ / Fn` | 0.013 |
| 2 | `rho` | `|F_t|/Fn`（切向/法向，摩擦锥利用率） | 0.002 |
| 3 | `w` | `qpos[7]+qpos[8]`（开口） | 0.056 m |
| 4 | `delta` | `clip((0.08−w)/0.08)`（挤压比） | 0.295 |
| 5 | `v_slip` | `‖v_obj − v_tcp‖` | 0.007 m/s（稳定）/ 0.12（草莓微滑） |
| 6 | slip | `v_slip > 0.03` | 0 |
| 7/8 | touch L/R | `‖F_L‖>0.5N`、`‖F_R‖>0.5N` | 1 / 1 |

来源：`links_map["panda_leftfinger"|"panda_rightfinger"].get_net_contact_forces()`、
`get_qpos()`、`fruit.linear_velocity`、`panda_hand_tcp.linear_velocity`。
`â` 用两指位置差 → **旋转不变**，手腕转多少都不影响法向/切向分解。

## 5. 训练目标

```
L = L_xyz + 2.0·L_grip + 1.0·L_KL + 0.5·L_phase + 1.0·L_slip
```
- `L_xyz`：16 步增量 xyz 的 MSE（标签 = **实际执行位移**，裁剪 ±6cm）
- `L_grip`：夹爪二分类 BCE（`pos_weight` 平衡开/合）
- `L_KL`：CVAE 正则（训练用 posterior，推理 z=0）
- `L_phase`：3 类相位 CE（标签从示教动作反推）
- `L_slip`：滑移**起始** BCE（`pos_weight` 自动，正样本约 3%）

数据：`dta-*` 173 局（0.06–0.18 m/s 域随机化）+ `sdagger3-*` 16 局失败片段
（`aux_only`，**只参与 L_slip**，不污染动作回归）；下探窗/料框减速窗各 3× 过采样。

## 6. 推理与部署（`ActPureRunner`）

```
obs(61) → 模型 → act[0]（第 0 步）          → 目标 = tcp + clip(Δ, ±6cm)
                 phase[0] argmax → 相位迟滞/承诺 → 回填下一步的 3 维 one-hot
                 slip[0] sigmoid  → 触觉决策：
                      · --slip-guard：搬运中 v_slip>阈值 → 搬运步长压到 1.2cm
                      · --regrasp   ：预测>阈值 → 张开→下沉2cm→再闭
                 grip[0] logit → EMA 平滑 → 搬运段锁爪（连续3步才松）
```
夹爪最大位移：接近 6cm/步、搬运 2cm/步；抓空 12 步自动重试；相位「下探」有承诺迟滞。

## 7. 与非触觉版的差异（一句话）

| | `act-wide-4c`（无触觉） | `act-ta-onslip`（触觉） |
| --- | --- | --- |
| 状态维度 | 49 + 3 = 52 | 49 + **9** + 3 = **61** |
| 辅助头 | 相位 3 类 | 相位 3 类 + **滑移 1 类** |
| 参数 | 6.876M | 6.881M（+0.005M） |
| 留出 AUROC（滑移） | — | **0.813** |
| 成功率（0.08 / 0.15） | 87.5% / 96.9% | 68.8%* / 43.8%* |

\* 同种子同数据对照 `act-nota-4c`（56.3% / 59.4%）：触觉重抓在 0.08 +12.5pp、
0.15 −15.6pp，类间互补；**阈值必须按类标定**（草莓成功搬运时中位滑移就有 12.4 cm/s，
全局 5 cm/s 阈值会误触发，见 `docs/model-architecture.md` 6.18）。

## 8. 已定位的局限

1. 触觉只经 `state_enc` 进入，没有独立 stem/token（文献 arXiv:2504.13618 建议独立编码后再融合）；
2. 夹爪力不可控（只有开/合），触觉无法转成"增力"动作；
3. 滑移预测 AUROC 0.813 可用，但**"滑移≠失败"**（草莓微滑仍成功），触发规则需按类标定；
4. `rho` 在 Fn≈0 时无意义（已 clamp）。
