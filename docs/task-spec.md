## 4. 观测与动作空间

- 观测：
  - 图像：`___`（分辨率、频率、是否对齐 depth）
  - 本体：关节角 / 末端位姿 / 夹爪开度
  - 语言指令（若用 VLA）：`___`
- 动作：
  - 空间：关节位置 / 关节速度 / 末端位姿增量（**必须二选一并写清坐标系**）
  - 频率：___ Hz
  - 夹爪：二值 or 连续
- 控制：位置控制 / 阻抗 / 力控；是否有底层安全限幅。

## 5. 成功判据

- 成功（strict）：物体进入目标区域且姿态满足 `___`，无掉落/挤压。
- 部分成功：抓取成功但放置位置偏差 < `___` mm。
- 失败分类：`detect_miss / grasp_miss / slip / collision / wrong_bin / timeout`。

## 6. 数据规范

- 每条 episode：`___` 秒 / `___` 帧，采集频率 `___` Hz。
- 目录结构（LeRobot 格式优先）：

```text
data/datasets/<name>/
├── meta/            # info.json, episodes.jsonl, tasks.jsonl, stats
├── data/chunk-000/  # parquet: observation.state, action, ...
└── videos/          # 或 images/
```

- 相机参数与标定：`assets/calib/<date>/`
- 采集工具：`lerobot record` / 自研遥操作 / ROS2 bag → 转换脚本

## 7. 评测协议

- 仿真：`___` 个随机种子 × `___` episode，随机化范围 `___`。
- 真机：`___` 种初始摆放 × `___` 次，人工判定，记录视频。
- 报告：成功率、节拍、失败分布、置信区间（Wilson interval）。
- 结果写入 `runs/<id>/metrics.json`，字段：

```json
{
  "success_rate": 0.0,
  "n_episodes": 0,
  "avg_duration_s": 0.0,
  "failure_counts": {},
  "notes": ""
}
```
