# 解决方案：动态传送带水果分拣

> 版本 v0.2.0 · 2026-11-17
> 目标：单 Franka Panda 在动态传送带上分拣 苹果 / 草莓 / 香蕉 / 梨，形成可复现、可评测、可迭代的研究基座。

## 1. 问题拆解

| 子问题 | 难点 | 本项目对应模块 |
| --- | --- | --- |
| 看见并识别 | 运动模糊、类别/位姿、传送带背景 | `perception/`（待接 RGB-D） |
| 预测运动 | 目标在推理与控制期间持续移动 | `control/intercept.py`（恒速/恒加速 + 卡尔曼） |
| 决定抓哪颗 | 吞吐最大化、可达性、TTC | `policies/`（TTC + 可达性排序） |
| 抓住动目标 | 时序对齐、夹爪闭合窗口 | `policies/scripted.py`（TRACK→DESCEND→CLOSE） |
| 放对框 | 类别→框映射、放置稳定性 | `scripted.py`（CARRY→LOWER→RELEASE） |
| 评测 | 动态条件下的可比指标 | `eval.py` + `scripts/benchmark.py` |

## 2. 系统分层（慢-快双频）

```
 10 Hz  ── 感知/识别/位姿 ──┐
                            ├── 目标选择 + 拦截点规划 (TTC)
 20 Hz  ── 视觉伺服/追踪 ────┤
                            ├── 抓取状态机（TRACK/DESCEND/CLOSE/CARRY/RELEASE）
 20–50 Hz ── 末端增量控制 ───┘
```

- **本仓库 v0.2**：单一 20 Hz 循环，策略直接用仿真真值位姿（oracle perception），作为性能上界与示教源。
- **v0.3+**：感知换成 RGB-D（色块+深度反投影），保留同一接口；再引入 30–50 Hz 残差纠偏（DSDyn 思路）。

## 5. 基线策略：预测拦截 + 顶部抓取

```
WAIT ──选最靠前可达目标──> TRACK ──对齐且进入可达区──> DESCEND
  ↑                         │                              │
  └── RELEASE <── LOWER <── CARRY <── 抓稳 ── CLOSE <───────┘
```

- **预瞄**：`x_target = x + v·t_lead`，t_lead=0.35 s（跟踪）/ 0.12 s（下探）。
- **抓取**：夹爪保持竖直向下，TCP 下探到水果几何中心；渐进闭爪（8 步）。
- **搬运**：先到身侧中转点 (0, −0.34, 0.60) 再横移到框上方，避免贴着带面横穿。
- **放置**：从 z=0.50 释放；成功后要求水果在框内、z≤0.16、速度<0.1 才算 settled。
- **看门狗**：单状态超时、掉件检测（物体离 TCP >0.10 m）、抓空重试。

## 6. 论文 → 模块映射（本项目的"思想来源"）

| 论文/思想 | 落到本项目的哪里 |
| --- | --- |
| AHEAD / Reflex / TEMPO（预测式抓取） | `t_lead` 预瞄、TRACK→COMMIT 状态机、速度估计 |
| LIBERO-Dynamic（动态基准） | 低摩擦带面 + 速度伺服、固定 20 Hz/步数预算、指标 ET/EP/EI |
| DSDyn-VLA（慢规划+快残差） | v0.3 的双频控制与 30 Hz Refiner 预留接口 |
| FASTER / DiscreteRTC / StreamPI（流式推理） | 未来 VLA 的异步执行与延迟预算；当前 20 Hz 闭环已满足 |
| DynamicWAM / TrajWAM / PhysMani（世界模型） | v0.4 的未来 mask/轨迹条件；当前用解析恒速外推替代 |
| 传送带调度（KARL 等） | 目标选择按 TTC + 可达性，而非"最近优先" |

## 7. 评测协议（对齐 LIBERO-Dynamic）

- 固定 20 Hz、1200 步上限、固定初始相位；
- 每个条件用同一 seed 序列，报告 **Wilson 95% CI**；
- 指标：分拣成功率、单件周期、抓取成功率、误抓率、掉落率、按类别成功率；
- 失败分类：`unreachable / grasp_miss / slip / wrong_bin / dropped / timeout`。

## 9. 已知限制（诚实记录）

1. 梨与香蕉的抓取成功率明显低于苹果/草莓（曲面/质量分布导致滑落）→ v0.3 用更好的抓取位姿采样 + 学习残差。
2. 传送带用"低摩擦带面 + 速度伺服"近似，而非真实皮带摩擦传动；横向漂移已被抑制，但缺少自然滚动。
3. 放置是从 0.50 m 高度释放，未建模碰撞损伤；后续加软体/损伤模型。
4. 单臂、静态料框、无遮挡；多臂协同与动态料框在 Non-goals。
