# 研究路线图

> 目标：在水果分拣任务上做出**可复现、可评测、能上真机**的具身智能系统。
> 每个阶段都要有明确的产出物和量化指标，不要跨阶段"顺手做"。

## 阶段 0：任务定义与环境（1–2 周）

| 事项 | 产出 |
| --- | --- |
| 明确分拣对象、料框、节拍、成功判据 | `docs/task-spec.md` 填完并评审 |
| 选定仿真后端（ManiSkill3 / Isaac Lab） | 一个能跑通的场景 + 1 条示教轨迹 |
| 真机链路（相机、机械臂、夹爪、ROS2 话题） | `ros2 topic hz` 全部达标，端到端 demo |
| 数据规范（采集频率、相机内外参、动作空间） | `docs/task-spec.md` 的数据一节 + 一条样例 episode |

**验收**：仿真里随机摆放 5 个水果，脚本能稳定跑完 20 个 episode 不崩；真机能录 10 条遥操作轨迹。
**风险**：相机标定/坐标系不一致 → 先在 `assets/` 固化标定文件和 URDF。

## 阶段 1：感知（2–4 周）

- 检测 + 分割：现有 `fruitsdetection` 迁移（YOLO / RT-DETR / SAM2）
- 6D 位姿 / 抓取点：FoundationPose、AnyGrasp、Contact-GraspNet
- 成熟度/瑕疵分类（可选，和分拣策略解耦）

| 指标 | 目标 |
| --- | --- |
| 检测 mAP@0.5 | ≥ 0.90（自建测试集） |
| 位姿 ADD(-S) / 抓取成功率（离线） | ≥ 85% |
| 单帧推理延迟（5090, fp16） | ≤ 30 ms |

## 阶段 2：仿真操作策略（3–6 周）

基线按复杂度递进，**先跑通再堆模型**：

1. 脚本化抓取（oracle 位姿）→ 确认动作空间/控制器没问题
2. ACT / Diffusion Policy（LeRobot 或自研）
3. DP3（点云输入）→ 验证 3D 表示是否值得
4. VLA 微调（OpenVLA / π0 / 自研 DynamicVLA）→ 语言条件 + 泛化

**验收**：ManiSkill3 自定义 `FruitSort-v0` 任务，≥ 3 个随机种子 × 100 episode，
报告成功率、平均完成时间、失败模式分布。

## 阶段 3：Sim2Real 与真机（4–8 周）

- 域随机化（光照、材质、摩擦、相机噪声、物体位姿）
- 真机少量微调（10–50 条示教）/ DAgger
- 部署：策略推理节点 + 安全限幅 + 急停

| 指标 | 目标 |
| --- | --- |
| 真机分拣成功率 | ≥ 80%（未见摆放，≥ 50 次） |
| 单件节拍 | ≤ 8 s |
| 策略推理频率 | ≥ 10 Hz（端到端） |

## 阶段 4：论文/系统化（持续）

- 消融：视觉输入（RGB vs RGB-D vs 点云）、动作表示、预训练权重、数据量
- 失败案例分析表（每类失败 ≥ 10 例）
- 复现包：代码 + 配置 + 权重 + 评测脚本
