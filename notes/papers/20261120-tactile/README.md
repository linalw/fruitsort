# 触觉论文速览与「可迁移性」评估（2026-11-20 批次，11 篇）

> 用途：判断这些融合触觉的工作对**我们这套仿真**（Franka 平行夹爪、开/合两档、
> 传送带四类水果、ACT-lite 纯模仿策略）有什么可借的。结论按"能不能落地"排序。

## 一句话总览

| 论文 | 核心机制 | 假定硬件 | 我们能复现吗 |
| --- | --- | --- | --- |
| **LeTac-MPC** | 可微 MPC，状态=(触觉嵌入, 开口, 速度)，输出**夹爪宽度** | 1-DoF 平行夹爪 + GelSight | **可以**（本质是位置控制） |
| **GraspTune** | 执行期**有界残余微动**（≤1.5mm/0.4mm/2°），闭合是"调度"：单侧强加载→暂停闭合 | 双指触觉图 100Hz，纯位置控制 | **可以**（同构） |
| **TacRefineNet** | 当前触觉 vs 目标触觉（Siamese）→ 回归腕位姿增量，循环"张—移—再抓" | 5 指 11DoF 触觉阵列 | 部分（需目标触觉模板） |
| **High-Bandwidth** | 纯触觉反射，"闭合/调整"两模式交替，antipodal 夹角判稳定 | 200Hz 触点+法向、8DoF 手指 | 判据可借，执行不行 |
| **RSC** | 10kHz 检滑移（20ms）→ 只在**内力子空间**加压 | 可连续加力的多指手 | 原则可借（平行两指退化为"同时加压"） |
| **T-Rex** | MoE 双频：慢专家出 chunk，快触觉专家 20Hz 对 chunk 内动作继续去噪 | 逐指力+形变图 | 架构思想可借，数据不够 |
| **CoorGrasp** | 接近/抓取两阶段按"能否 wrench 平衡"切换，抓取期按平衡分摊力 | 多指力控 + 在线 MPC | 否（需力控） |
| **Secure&Gentle** | 显式两条不等式 `F>mg/ν`（不滑）/`F<F_max`（不损），FSM 在线探边 | 可调力回路 100Hz | 否（需力控），但**指标定义可借** |
| TacMan-Turbo / Vi-TacMan / TactileAloha | VLA/IL 中的触觉融合（token 化、双频、双臂） | 大规模数据 + 触觉阵列 | 数据量不够 |

## 最重要的三点（对我们直接有用）

### 1. 论文里触觉都进**独立的快速小环**，而不是塞进大策略

T-Rex（20Hz 触觉专家）、High-Bandwidth（200Hz 反射）、RSC（QP 加力）、LeTac（25Hz MPC）
无一例外：**大模型负责"去哪"，触觉小环负责"这一抓稳不稳、怎么立刻改"**。

这解释了我们所有失败：
- 触觉拼进 state → 62.5% vs 58.3%（无收益）
- 触觉独立 token → 3/3 掉到 1/3
- 力作为动作第 5 维 → 0/3

**让 6.9M 的策略自己从 170 条示教里学"触觉该怎么用"是不现实的**；正确做法是我们后来做对的：
独立 DropNet（20k 参数）→ AUROC 0.937。

### 2. GraspTune 的触觉不是观测，是**"动作→接触后果"的监督**

它的触觉标签是"这一步微动会让左右指接触怎么变"，用于学接触语义；闭合是**调度**
（单侧强加载就暂停闭合），不是连续力控。**这一点我们完全没做**：我们只把 Fn/Fasym 当输入，
没有"微动→后果"的监督。

### 3. LeTac 与我们同构：**输出的是夹爪宽度**，不是力

它靠"以 4.5mm/s 慢松爪到滑移、记下滑移时的宽度"来标定每类物体的 `w*`。
我们可以直接照抄：每类水果用示教统计 `w*`（成功抓取时的中位开口），
闭合时把目标设为 `w*` 而不是"一直闭到底"——这是**位置等价的力控**。

## 实测：两条接触期机制在我们的场景里无效

| 机制（论文） | 我们的实现 | 0.08 四类各 8 局 |
| --- | --- | --- |
| 抓取验证门 + 有偏重试（①） | 进搬运段 5 步后判 双指力>2N / 对称度<0.5 / 相对速度<0.02，不达标开爪+偏 5mm 重试 | 28/32（= 基线，**一次都没触发**） |
| 单侧接触微伺服（②） | 闭爪时若只有一指受力 → 朝弱侧平移 2mm | 梨 4/8、香蕉 8/8（= 基线） |

**原因**：我们的失败根本到不了接触期——`carry=0`、`Fn=0`，水果原样通过。
0.08 的梨有一次峰值 Fn 89N（压得很重）但仍在搬运中丢。**接触期的补救机制救不了"没碰到"**。

## 结论：下一步该做什么

1. **接触前**才是瓶颈：把"预瞄/对准"做扎实（更长预瞄、或按类标定的拦截点），
   或给动作空间加**探触原语**（轻触→读力→重定位），这是论文里唯一没覆盖、
   而我们失败最集中的一段；
2. **宽度设定点（LeTac 式）**值得一试：闭合到 `w*` 而不是闭到底，能同时改善
   "小果被挤飞"和"大果夹不紧"，且**不需要力控接口**；
3. **触觉只做独立监控/触发**（已验证 AUROC 0.937），不要再塞进策略。
