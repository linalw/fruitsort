# DSDyn-VLA：双流动态操作（运动感知 + 未来感知 + 实时纠偏）

## 一句话结论

动态操作 = 三个独立 gap（感知 / 延迟 / 控制），对应三个可插拔模块：光流极坐标图、运动学前滚的本体状态、30 Hz RL 残差。慢流 3 Hz 规划 + 快流 30 Hz 纠偏。

## 方法核心

- 最终动作：`a_final = a_slow_t + π_fast(s_t, a_slow_t)`
- 光流极坐标映射：Hue=atan2(v,u)、Sat=‖v‖ → 3 通道图送 CLIP 系 ViT，与 RGB 特征拼接。
- 未来感知：`q̂_future = f_kin(q_query, Σ A_buffer)`；训练时把 I_t 与 t+Δ 的本体/动作配对（随机时间偏移），推理零开销。
- Res-Refiner：ResNet-10 + MLP，残差限幅 10% 动作范围，RLPD（50% 离线 + 50% 在线），3 ms 推理。
- 两阶段：SFT 动作专家 → 冻结 planner 只训 refiner（稀疏二值奖励）。

## 对 Fruitsort 的可执行建议

1. **三 gap 当设计 checklist**：我们的基线先补"控制 gap"（30 Hz 追踪/纠偏），再补"感知 gap"（速度估计），最后才是大模型。
2. **运动学前滚 + 随机 time-shift**：推理零成本，可直接加到未来 ACT/DP 的 dataloader。
3. **残差 RL 优于 SFT 残差**（48.5 vs 37.5）；先仿真训，再 sim2real。
4. **慢规划 + 快纠偏**：本仓库脚本策略已按 20 Hz 控制、每步重规划实现；后续把 5 Hz 规划器 + 50 Hz 残差接上。
5. 传送带抓取/分类分拣任务命名可参考 DynBench 的 9 任务。
