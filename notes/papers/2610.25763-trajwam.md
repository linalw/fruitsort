## 一句话结论

不要让视频世界模型"自由想象"目标怎么动——先用 mask 历史**显式预测未来 8 帧目标 mask**（一个 2D U-Net，一次前向），再用轻量 Trajectory ControlNet 把视频生成"掰"到这条轨迹上；即便蒸馏到一步推理，anticipation 通路仍在：DOMINO 43.54% / 108.5 ms，真机传送带抓取 77.9%。对我们最有价值的是"**对象级未来轨迹**是最便宜、最可控的中间表征"这一判断。

## 要解决的问题

- 现有 WAM 在**全帧级别**预测场景演化，机器人自身运动与背景变化会淹没目标运动；任务相关轨迹只被间接表示，无法在生成时显式控制。
- 迭代 video-action 去噪延迟大，预测在执行前就过期。
- 两条已有加速路线各有问题：跳过未来想象（Fast-WAM）⇒ 丢掉预测通路；压缩去噪（Flash-WAM 等）⇒ 无法保证"空间显式的运动条件"在激进压缩后还有效。
- 需要一个 **object-centric 的未来表征**：既指定目标的空间轨迹，又与动作耦合。

## 方法核心

### A 对象级未来轨迹预测

```
m_i = S(o_i^third, ℓ)                 # 冻结的语言条件分割（SAM3），只用固定第三人称视角
M_t^- = K 帧 mask（K=4, temporal stride s=4）
M_t^+ = σ( g_φ(M_t^-) )               # 一个紧凑 2D U-Net，一次前向出全部 Hv=8 帧未来 mask
```

- 只用第三人称视角：腕部相机会随臂动、间歇丢失目标，无法维持一致 mask 历史（腕部只提供 RGB）。
- 损失：logits 上 BCE + 概率上 soft Dice，各 0.5；训练 20 epoch、batch 128、lr 1e-3。
- 关键：这是一个**和机器人动作无关的运动外推器**（论文明确说目标是独立运动物体）。

### B 轨迹条件的 video–action 建模

- `z_M = E_vae(M_t^+)`（预训练视频 VAE），把 mask 序列编码成 trajectory latent。
- **Trajectory ControlNet**：与视频骨干同深度，但宽度 3072→512；零初始化卷积投影注入逐层残差：

```
h̃_v^j = h_v^j + Z_j ( A_φ^j(z_M, s_v) )      # s_v = 视频 flow time
```

- **非对称 video–action attention**：

```
[h_v; h_a] = softmax( M(QKᵀ/√d) ) V
M(·): video query 只看 video KV；action query 看 action+video KV
```

即动作能读"被轨迹控制的未来表征"，而视频预测不受动作 token 影响。
- 骨干：视频模型与动作专家都从 **Wan2.2-5B** 初始化（动作专家宽度 3072→1024），VAE/text encoder/视频骨干训练时冻结；只训 ControlNet + 零初始化投影 + 动作专家（5,000 步、global batch 128、lr 5e-5）。

### C 训练目标

两模态独立采样噪声与 flow time，联合 flow matching：

```
x_q^{s_q} = (1-s_q)x_q + s_q ε_q ,  ε_q ~ N(0,I)
L = E Σ_{q∈{v,a}} λ_q ‖ û_q - (ε_q - x_q) ‖²
C = (y_t, z_M, c)      # 当前帧 latent、轨迹 latent、语言
```

真值未来动作监督动作分支；轨迹条件通过"受控的视频预测"在同一前向里影响动作。

### D 三段解耦蒸馏（one-step 部署）

1. **视频骨干 DMD**：学生 `ŷ⁰ = G_ψ(ε_v | y_t, c)`；冻结 real-score `f_Θ` + 可训 fake-score `f_ω`，`Δ_DMD = (ŷ⁰_fake - ŷ⁰_real)/(mean|·|+ε)`，`L_DMD = E ½‖ŷ⁰ - sg[ŷ⁰ - Δ_DMD]‖²`；5,000 步、batch 8、lr 5e-7 / 1e-7、1:5 交替。
2. **Trajectory adapter 重对齐**：从慢 ControlNet 初始化，冻结快视频生成器；`L_rec = ‖ŷ⁰_fast - y_{>t}‖²` + 对抗（判别器 = 冻结多步视频模型 + 轻量可训 attention + MLP 头）；1,000 步、lr 2e-6。
3. **Action rollout 蒸馏**：学生 1v/1a 对齐教师 10v/10a 的**完整 action chunk**（不是中间 flow velocity，也不是 GT 动作）：

```
ℓ_{b,t} = (1/D_a) Σ_d ( â_S - sg(â_T) )²,   L_act = 加权平均（mask 掉 padding）
```

2,000 步、batch 4、lr 1e-6。

### E 推理流程（闭环）

- 分割：冻结 SAM3 **异步**运行，平均 69.1 ms；重规划时用"最新可用"的 mask 历史，**不等当前帧分割**，缓冲区动作继续执行。
- 轨迹预测器：K=4 历史 mask → 8 帧未来 mask（这是全流程最便宜的模块）。
- 一步视频 + 一步动作 ⇒ 108.5 ms/query；输出 `Ta=32` 个动作，执行 8 个后重规划；真机全部启用 RTC。

## 世界模型三问（按任务清单）

- **物体运动怎么表示**：**显式的像素级 mask 轨迹**（8 帧未来前景概率图）。不是 3D、不是点轨迹，但空间上可读、可检查、可用经典方法替代——这是全文最可迁移的判断。
- **未来帧怎么预测**：mask 预测器一次前向出全部 8 帧；视频分支在这些 mask 的 ControlNet 引导下生成未来 latent；一步蒸馏后视频只前向一次。
- **推理速度**：108.5 ms/query（DOMINO，RTX 5090）；分割 69.1 ms 异步并行；一步视频 + 一步动作。
- **是否需要大规模预训练**：**是**。视频/动作专家都从 Wan2.2-5B 初始化，还需要 Fast-WAM-Joint 的预训练权重；蒸馏阶段要同时驻留 5B real-score 教师。

## 对 Fruitsort 的可执行建议（单 Franka + 传送带，苹果/草莓/香蕉/梨）

### 可直接落地的"对象级轨迹"路线（推荐先做，30% 学习 + 70% 经典）

1. **mask 用经典方法拿**：传送带背景固定 ⇒ HSV/深度阈值 + 连通域即可给苹果、香蕉、梨稳定 mask；草莓用颜色 + 圆度可区分。论文用 SAM3 是因为开放场景，我们不需要（他们的 mask 源消融显示 SAM3→GroundedSAM2 只差 2.11 点，说明**这个模块不是瓶颈**）。
2. **mask 预测器可先用恒速外推**：`m_{t+k} = warp(m_t, k·v̂)`，`v̂` 来自卡尔曼。论文的 U-Net 在匀速直线运动上几乎不可能赢过解析外推；先跑这个当 baseline，把"未来轨迹"接口定下来。
3. **不用视频模型也能用它的核心思想**：把"预测的未来 mask / 未来质心序列"直接作为小 BC 策略（或 flow-matching 动作头）的条件输入。论文的 Static vs Predicted 消融（20.90 vs 47.30）说明**轨迹条件本身贡献极大**，而 ControlNet+5B 只是把它注入视频分支的一种方式。
4. 抓取时机直接由轨迹给出：`t* = argmin_t ‖p̂(t) - p_grasp_ready‖`，夹爪提前闭合量用标定补偿。

### 值得接的学习模块

1. **mask 轨迹预测器**（小 U-Net / ConvGRU，输入 4 帧 mask，输出 8 帧）：当出现变速、转弯、水果相互推挤时，学习模型才会超过恒速外推。这是最划算的一处学习化。
2. **动作头条件化**：把 8 帧未来 mask（或降采样成 8×2 的质心+尺度序列）编码成 token，喂给 diffusion/flow 动作头。改动小、可解释、易做消融。
3. **异步分割 + 动作缓冲**：论文的"不等当前帧分割、用最新可用 mask"是纯工程 trick，直接抄。
4. **RTC**：`Ta=32 执行 8` 的节奏对传送带很合适（0.4 s 重规划周期），先上 RTC 再谈模型。

### 不建议现在做

- Wan2.2-5B + ControlNet + 三段蒸馏。除算力外，代码未放出（"Code coming soon"），复现只能照论文重写。
- 双 Piper 臂配置：论文真机是双臂（左右各一），我们单臂要重做数据采集与工作空间设计，收益未知。

### 与我们任务的差异（要注意）

- 论文目标物是**独立运动**的刚体（香蕉、瓶子、胶带、玩偶），作者在结论里明确说"扩展到 action-dependent 物体动力学是未来工作"。我们的分拣还要"抓起来放进箱子"，接触后物体会响应动作 ⇒ 未来 mask 预测在接触后会失准，只能在**接近段**用。
- 高速下瓶子只有 7/20 成功，说明细长/光滑刚体仍是弱项；我们的香蕉（细长、易滚）大概率类似。

| 项 | 估计/事实 |

| 训练硬件 | H200（蒸馏需 real-score 5B 教师 + 学生 + ControlNet + 动作专家共存）；单 5090 32GB 风险高 |
| 推理硬件 | RTX 5090 32GB 可跑（108.5 ms 即在该卡测得） |
| 数据 | DOMINO 1,750 条（50/任务）；真机 400 条（200/任务） |
| 训练步数 | 主训练 5,000 + 蒸馏 5,000 / 1,000 / 2,000（步数少，但每步重） |
| 代码 | 仓库存在但**代码未发布**；Fast-WAM-Joint 权重需另找 |

风险：
1. **代码未放出** ⇒ 复现成本主要是"重写"，不是"调通"。
2. 依赖 Fast-WAM-Joint 初始化（Wan2.2-5B 派生），链路长、版本敏感。
3. mask 质量依赖分割；草莓这类小目标、多目标重叠时，mask 历史会抖，轨迹预测误差会被 ControlNet 放大。
4. 真机实验每格 20 trials，且只有两类运动（直线/转盘），对我们的复合场景外推有限。

## 原文关键片段

1. "Existing WAMs predict scene evolution at the full-frame level, where robot-induced changes can dominate the imagined future. In dynamic manipulation, task success may instead depend critically on target motion that evolves independently of the robot's actions."
2. "Given a causal history M_t^-, which consists of K masks sampled with temporal stride s up to the current time t, a compact 2D U-Net g_φ predicts all H_v future masks in one forward pass."
3. "We use the fixed third-person view because it provides a stable global reference for observing the target-object trajectory. In contrast, the wrist-mounted cameras move with the robot arms and may intermittently lose sight of the target."
4. "The student is trained to match the action chunk produced by the teacher's multi-step rollout, rather than an intermediate flow velocity or a ground-truth action-flow target."
5. "Static performs worse than Black, possibly because repeating the current mask imposes an incorrect stationary trajectory that misguides future imagination as the target moves."
6. "the current experiments focus primarily on independently moving target objects; extending trajectory forecasting to action-dependent object dynamics remains an important direction."
